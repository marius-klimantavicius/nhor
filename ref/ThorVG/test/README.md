# ThorVG Unit Tests

<p align="center">
  <img width="550" height="auto" src="https://raw.githubusercontent.com/thorvg/thorvg.site/refs/heads/main/readme/logo/animated_brand.svg">
</p>

This repository contains the official ThorVG unit test suite, built using the [doctest](https://github.com/doctest/doctest) C++ testing framework. It is integrated into the main ThorVG repository as a Git submodule.

For setup instructions and usage details, see the [ThorVG Unit Testing Guide](https://github.com/thorvg/thorvg/wiki/Unit-Tests).
